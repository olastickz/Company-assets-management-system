# Sample data for vehicles

This directory contains sample CSV files for the vehicles app.

## Files

- `sample_equipment.csv` — equipment records for import or testing
- `sample_vehicles.csv` — vehicle records for import or testing

## Usage

- Review the column headers before importing
- Use an import script or management command against `docs/sample_data/`

## Notes

- These files are stored for development and documentation
- To use as Django fixtures, move them to `vehicles/fixtures/` and convert to fixture format
