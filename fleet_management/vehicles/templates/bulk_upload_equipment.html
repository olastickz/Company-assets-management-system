📋 CSV Format Requirements:

Your CSV file should have the following columns (headers required):

Required columns:
• name - Equipment name (e.g., "Dell Desktop Computer")
• equipment_type - computer, printer, scanner, copier, ac, generator, furniture, other

Optional columns:
• description - Detailed description
• location - Office location (e.g., "Office 1")
• status - active, inactive, damaged (default: active)
• purchase_date - YYYY-MM-DD format
• warranty_expiry - YYYY-MM-DD format
• cost - Purchase cost (e.g., 5000.00)
• notes - Additional notes

📝 Example CSV:

name,equipment_type,location,status,purchase_date,cost
Dell Desktop Computer,computer,Office 1,active,2022-01-15,3500.00
HP LaserJet Printer,printer,Office 1,active,2021-06-20,2500.00
LG Air Conditioner,ac,Office 2,active,2020-03-10,8000.00

📊 Excel Format (Laptop Tagging):

Your Excel file should include columns like:

SUBSIDIARY | ITEM DESCRIPTION | LOCATION | QTY | SERIAL NUMBER | YOP (Year) | TAG NUMBER | USER | REMARKS

The system will automatically extract and organize this data into computer equipment entries with serial numbers stored in notes.

✅ Tips:

  • Use YYYY-MM-DD format for all dates (e.g., 2025-12-31)
  • Leave date fields empty if not available
  • Valid equipment types: computer, printer, scanner, copier, ac, generator, furniture, other
  • Default status is "active" if not specified
  • Cost should be a numerical value
  • For Excel files: Serial numbers and tag numbers are automatically stored in notes
  • Choose only ONE file type per upload
