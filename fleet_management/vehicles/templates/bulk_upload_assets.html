📋 CSV Format Requirements:

Your CSV file should have the following columns (headers required):

Required columns:
• name - Asset name (e.g., "Toyota Corolla")
• license_plate - License plate number (e.g., "ABC-123")
• vin_number - Asset VIN number

Optional columns:
• make - Asset make or brand
• model - Asset model
• vehicle_type - Asset type value or category
• hackney_permit - YYYY-MM-DD format

⚠️ Note: Any dates with 2025 or earlier will be marked as PENDING for you to update later.

📝 Example CSV:

name,license_plate,vin_number,make,model,vehicle_type,insurance_expiry,roadworthy_expiry
Toyota Hiace,ABC-123,1HGBH41JXMN109186,Toyota,Hiace,van,2026-12-31,2026-06-30
Nissan Urvan,XYZ-789,1N4AL11D75C109151,Nissan,Urvan,van,2027-11-30,2026-12-31

📊 Excel Format:

Your Excel file should include the columns mentioned above. The system will automatically extract the data.

📝 Word Document Format (Asset Document.docx):

The Word document should contain a table with these columns:

S/N | Asset Make | Registration No | Road worthiness | Hackney Permit | Asset License | Insurance Status

✅ Tips:

  • Use YYYY-MM-DD format for all dates (e.g., 2026-12-31)
  • Leave date fields empty if not available - they'll be marked as pending
  • 📌 Any dates showing 2025 will be automatically marked as PENDING - you can edit them later
  • License plate should be unique
  • Default asset type is "car" if not specified
  • Duplicates will fail - ensure unique license plates
  • Choose only ONE file type per upload
