# Company Assets Management System

A comprehensive Fleet and Company Asset Management System built with Django to help organizations efficiently manage vehicles, equipment, staff, maintenance schedules, company documents, and asset transfers.

---

## Features

- Vehicle Management
- Equipment Management
- Staff Management
- Maintenance Scheduling
- Company Documents
- Email Notifications
- Asset Transfers
- User Authentication
- Dashboard for Asset Monitoring

---

## Technologies Used

- Python
- Django
- SQLite
- HTML5
- CSS3
- JavaScript
- Bootstrap

---

## Installation

```bash
git clone https://github.com/olastickz/Company-assets-management-system.git
cd Company-assets-management-system
pip install -r root-requirements.txt
cd fleet_management
python manage.py migrate
python manage.py runserver
```

---

## Usage

After starting the development server, open your browser and navigate to:

```
http://127.0.0.1:8000/
```

Log in using your administrator account to access the system and manage:

- Vehicles
- Equipment
- Staff
- Company Documents
- Maintenance Records
- Asset Transfers
